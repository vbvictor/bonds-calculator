# bond-rate-calculator

**Живёт тут: https://vbvictor.github.io/bonds-calculator/**

Статическое SPA: задаёте свой прогноз траектории ключевой ставки ЦБ РФ и сравниваете
облигации — флоатеры и фиксы — по фактической доходности к погашению с учётом
реинвестирования купонов.

Главный ответ, который даёт приложение, — **точка безразличия**: насколько должна
сдвинуться траектория, чтобы победитель поменялся.

## Запуск

Всё через `make`, `make help` покажет список:

```sh
make up            # зависимости и дев-сервер в фоне
make down          # остановить всё
make status        # что сейчас запущено и на каких портах
make logs          # хвост лога дев-сервера

make check         # то же, что гоняет CI: типы, тесты, сборка
make test          # тесты один раз
make watch         # тесты в режиме наблюдения
make preview       # собрать и поднять превью продакшен-сборки
make ref           # напечатать эталонные числа из reference/ref.py
make clean         # убрать dist, логи и кеши
```

Порты переопределяются: `make up DEV_PORT=3000`.

Дев-сервер и превью запускаются в фоне, их PID лежат в `.run/`. `make down` гасит
только то, что запускали сами: если порт занял чужой процесс, `make up` честно
упадёт с ошибкой vite, а `make down` чужое не тронет.

Без make — обычные скрипты npm: `npm run dev`, `npm test`, `npm run build`.

Приложение не ходит в сеть: ни котировок, ни ISS API, ни внешних шрифтов.
Шрифты (IBM Plex Sans/Mono, подмножества latin и cyrillic) собираются из
`node_modules` в бандл.

## Структура

```
src/
  model/        чистые функции: ни React, ни DOM, ни хуков
    types.ts        Bond, RatePoint, CalcResult, CalcContext
    rates.ts        ksAt, avgKS, dateToMonth, addMonths
    cbrCalendar.ts  подтверждённые даты заседаний ЦБ
    engine.ts       couponSchedule, grow, calcBond, calcSeries
    scenarios.ts    свип по shift, точки безразличия, смена лидера
    generator.ts    генератор сетки точек
    engine.test.ts  приёмочные тесты A–H
  components/   UI
  state/        состояние, URL-сериализация, селекторы
  styles/
reference/
  ref.py          референсная реализация, источник эталонных чисел
  prototype.html  исходный макет, источник визуального языка
```

**Инвариант:** в `src/model/` нет импортов React и обращений к DOM. Это условие
тестируемости.

## Модель

Шаг — календарный месяц, месяц 0 — дата старта. Номинал всегда 1000. Ставка меняется
скачками, только в даты точек траектории, и между ними постоянна (`mode: 'step'`);
линейная интерполяция есть, но как опция — она физически неверна и заметно завышает
преимущество фикса.

Купоны реинвестируются помесячно по ставке «ключевая плюс спред» с **номинальной**
капитализацией: годовая ставка делится на 12, корень двенадцатой степени не извлекается —
так работают фонды денежного рынка. Купон, пришедший ровно в месяц погашения, не растёт.

Эталонные числа — в `reference/ref.py`. Допуск 1e−6 по доходности, 1e−3 по суммам.
**Расхождение с `ref.py` — баг реализации, а не повод поправить эталон.**

```sh
python3 reference/ref.py   # напечатает эталоны тестов A, B, C, D, G
```

## Деплой на GitHub Pages

`.github/workflows/deploy.yml` гоняет типы и тесты **до** сборки: разошлась модель
с эталонами — деплоя не будет.

Один раз после первого пуша надо включить сам Pages, иначе сборка проходит,
а публикация падает с `404 … Ensure GitHub Pages has been enabled`.
**Settings → Pages → Source → GitHub Actions**, не ветка. Или одной командой:

```sh
gh api -X POST repos/vbvictor/bonds-calculator/pages -f build_type=workflow
```

Здесь это уже сделано.

`base` в `vite.config.ts` обязан совпадать с именем репозитория:

```ts
base: '/bonds-calculator/',
```

Иначе Pages отдаст белый экран и 404 по ассетам.

### Приватный репозиторий

GitHub Pages из приватного репозитория работает **не на всех тарифах**:

| Тариф | Pages из приватного репо | Видимость сайта |
|---|---|---|
| Free | недоступен, workflow упадёт | — |
| Pro / Team | работает | сайт публичный |
| Enterprise Cloud | работает | можно ограничить доступ |

То есть приватный репозиторий сам по себе не делает страницу приватной. На Free
единственный вариант — сделать репозиторий публичным.

## Чего модель не делает

Налоги, НКД при покупке, комиссии, кредитный риск, амортизация, оферты, продажа до
погашения, терминальная оценка цены. Бумага удерживается до погашения, дефолта нет.

Приложение не является инвестиционной рекомендацией.
